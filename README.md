Deskripsi: ### Deskripsi Program

**Adventure Camp – Sistem Penyewaan Peralatan Camping** merupakan program berbasis console yang dibuat menggunakan bahasa pemrograman C. Program ini dirancang untuk mempermudah proses penyewaan perlengkapan camping, mulai dari pemilihan peralatan, pencatatan data penyewa, perhitungan biaya, hingga penyimpanan riwayat transaksi.

Program menyediakan lima jenis peralatan camping, yaitu tenda kapasitas 4 orang, sleeping bag, kompor portable, matras camping, dan lampu camping. Setiap peralatan memiliki harga sewa yang berbeda untuk setiap harinya.

Pengguna dapat memilih peralatan yang ingin disewa, memasukkan jumlah unit, serta menentukan lama penyewaan. Selanjutnya, program akan menghitung total biaya secara otomatis berdasarkan harga peralatan, jumlah unit, dan lama penyewaan.

Program juga menerapkan sistem diskon berdasarkan durasi penyewaan, yaitu 10% untuk penyewaan selama 3–4 hari dan 15% untuk penyewaan selama 5 hari atau lebih. Setelah proses perhitungan selesai, program akan menampilkan struk pembayaran yang berisi rincian transaksi.

Selain itu, program dilengkapi fitur riwayat transaksi yang menggunakan array untuk menyimpan data penyewaan selama program berjalan. Pengguna dapat melihat jumlah transaksi yang telah dilakukan beserta total pendapatan yang diperoleh.

Dalam pembuatannya, program menerapkan konsep dasar pemrograman C, seperti penggunaan variabel, array, fungsi, percabangan `if-else` dan `switch-case`, serta perulangan `while`, `do-while`, dan `for`.

Dengan adanya program ini, proses penyewaan peralatan camping menjadi lebih praktis, terstruktur, dan efisien dibandingkan pencatatan secara manual.
